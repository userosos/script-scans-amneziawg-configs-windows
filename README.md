# AmneziaWG Configs Tester for Windows

Автоматический скрипт на PowerShell для пакетного тестирования конфигурационных файлов AmneziaWG (`.conf`) в Windows 10 / 11. 

Скрипт поочередно поднимает туннели, проверяет реальное прохождение трафика и сортирует файлы по папкам: рабочие — в `working`, недоступные или заблокированные — в `failed`.

---

## ⚡ Особенности

- **Поддержка параметров обфускации AmneziaWG:** корректно отрабатывает конфиги со специальными параметрами защиты от блокировок (`Jc`, `Jmin`, `Jmax`, `S1`, `S2`, `H1`–`H4`).
- **Защита от ложных срабатываний:** скрипт сначала определяет ваш реальный домашний IP-адрес. Конфиг считается рабочим (`OK`) только в том случае, если IP действительно сменился на адрес VPN-сервера.
- **Работа без зависаний и окон с ошибками:** удаление служб туннелей реализовано через системную утилиту Windows `sc.exe`, что предотвращает появление всплывающих модальных окон при таймаутах.
- **Рекурсивный поиск:** находит файлы конфигураций как в корневой папке, так и во всех вложенных поддиректориях (удобно при распаковке архивов).
- **Экспорт отчета:** формирует итоговый файл `results.csv` со статусами и полученными IP-адресами.

---

## 📋 Требования

1. **ОС:** Windows 10 или Windows 11 (64-bit).
2. **Права:** Запуск терминала от имени **Администратора** (необходимо для управления системными службами сетевых туннелей).
3. **Клиент:** Установленный [AmneziaWG для Windows](https://github.com/amnezia-vpn/amneziawg-windows-client/releases) (путь по умолчанию: `C:\Program Files\AmneziaWG\amneziawg.exe`).
