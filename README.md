# AmneziaWG Configs Tester for Windows

Автоматизированный PowerShell-скрипт для пакетного тестирования конфигураций AmneziaWG (`.conf`) в среде Windows 10 и 11.

Скрипт поочередно поднимает туннели, проверяет реальное прохождение трафика через интернет-шлюз и сортирует файлы: работоспособные перемещаются в папку `working/`, а заблокированные или недоступные — в `failed/`.

---

## ⚡ Особенности

* **Поддержка параметров AmneziaWG:** корректная работа со специальными параметрами протокола (`Jc`, `Jmin`, `Jmax`, `S1`, `S2`, `H1`–`H4`).
* **Защита от ложных срабатываний:** скрипт определяет ваш домашний IP-адрес до старта. Конфиг считается рабочим (`OK`) только в том случае, если IP действительно сменился на адрес VPN-сервера.
* **Работа без зависаний и всплывающих окон:** управление службами туннелей реализовано через системную утилиту Windows `sc.exe`, что предотвращает появление блокирующих окон с ошибками (*«The specified service does not exist»*).
* **Рекурсивный поиск:** скрипт автоматически находит файлы `.conf` как в текущей папке, так и во всех вложенных поддиректориях.
* **Сводный отчет:** результаты проверки (статус, имя файла, полученный VPN IP) автоматически фиксируются в `results.csv`.

---

## 📋 Системные требования

* **ОС:** Windows 10 (версия 1803 и новее) или Windows 11 (64-bit).
* **Интерпретатор:** PowerShell 5.1 или PowerShell 7+.
* **Сетевая утилита:** встроенный `curl.exe` (входит в комплект Windows 10/11 по умолчанию).
* **VPN-клиент:** установленный [AmneziaWG для Windows](https://github.com/amnezia-vpn/amneziawg-windows-client/releases) (стандартный путь: `C:\Program Files\AmneziaWG\amneziawg.exe`).
* **Права доступа:** консоль PowerShell должна быть запущена **от имени Администратора**.

## 🚀 Установка и подготовка

### Способ 1. Клонирование через Git

```bash
git clone [https://github.com/userosos/script-scans-amneziawg-configs-windows.git](https://github.com/userosos/script-scans-amneziawg-configs-windows.git)
cd script-scans-amneziawg-configs-windows
```

### Способ 2. Скачивание ZIP-архивом

1. В верхней части страницы репозитория нажмите зеленую кнопку **Code** -> **Download ZIP**.
2. Распакуйте скачанный архив в любую папку (например, `C:\AWG_Test`).

### Размещение файлов конфигурации

Скопируйте ваши файлы `.conf` в папку со скриптом `test_awg.ps1`. Допускается как размещение файлов прямо в корне, так и во вложенных папках (например, после распаковки сторонних архивов).

## 🛠️ Инструкция по запуску

1. Нажмите клавиши **Win + X** и выберите пункт **«Терминал (Администратор)»** или найдите PowerShell в меню «Пуск», нажмите правой кнопкой мыши и выберите **«Запуск от имени администратора»**.
2. Перейдите в каталог со скриптом:
   ```powershell
   cd "C:\Путь\К\Папке"
   ```
3. Разрешите запуск скриптов для текущего сеанса PowerShell:
   ```powershell
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   ```
4. Запустите скрипт тестирования:
   ```powershell
   .\test_awg.ps1
   ```

## 📂 Структура каталога после проверки

После завершения тестирования файлы будут распределены следующим образом:

```text
├── working/          # Рабочие конфигурации (IP успешно сменился)
├── failed/           # Нерабочие или заблокированные конфигурации
├── results.csv       # Таблица с результатами и IP-адресами
├── test_awg.ps1      # Скрипт тестирования
└── README.md
```

Пример содержимого `results.csv`:
```csv
config,status,external_ip
NL_Amsterdam_01.conf,SUCCESS,185.156.46.22
US_NewYork_05.conf,FAIL,
DE_Frankfurt_02.conf,SUCCESS,194.126.177.10
```

## 🔄 Повторное тестирование

Если вам понадобится вернуть все отсортированные файлы обратно в общую папку для нового прогона (например, при проверке через другого провайдера), выполните в PowerShell:

```powershell
Get-ChildItem .\working, .\failed -Filter *.conf -ErrorAction SilentlyContinue | Move-Item -Destination .
```

## ⚙️ Тонкая настройка

Параметры скрипта можно скорректировать под свои сетевые условия:

* **Время ожидания соединения (`Start-Sleep -Seconds 4`):** если пинг до серверов высокий или интернет-канал перегружен, увеличьте задержку до `5`–`6` секунд.
* **Таймаут curl (`--max-time 5`):** ограничивает время ожидания ответа от проверяющего сервера.
* **Сервис проверки IP (`https://api.ipify.org`):** можно заменить на любой аналогичный ресурс (например, `https://icanhazip.com` или `https://ifconfig.me/ip`).
* **Путь к `amneziawg.exe`:** массив `$AwgPaths` содержит перечень стандартных путей. При нестандартной установке добавьте свой путь первым элементом.

## ❓ Часто задаваемые вопросы (FAQ)

**В: Во время теста кратковременно пропадает интернет. Это нормально?**  
О: Да. Если в конфиге прописан маршрут `AllowedIPs = 0.0.0.0/0`, Windows переключает весь сетевой трафик на проверяемый интерфейс на 3–4 секунды.

**В: Ошибка: «Клиент AmneziaWG не найден!».**  
О: Убедитесь, что установлен именно клиент **AmneziaWG** (не стандартный WireGuard). Исполняемый файл должен находиться по пути `C:\Program Files\AmneziaWG\amneziawg.exe`.

**В: Ошибка безопасности `PSSecurityException` при старте.**  
О: Windows по умолчанию блокирует запуск сторонних скриптов. Обязательно выполните команду `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` перед вызовом `.\test_awg.ps1`.
